# Experiment-6-Layout-Code

Aim

To create a mobile application in Android Studio that illustrates various Android layout managers including LinearLayout, RelativeLayout, and TableLayout with activity navigation.

Algorithm
1. Open Android Studio and create a new application project.
2. Create the MainActivity and add three buttons for different layouts.
3. Create XML layout files for Linear, Relative, and Table layouts.
4. Create corresponding Java activity classes for each layout screen.
5. Add UI elements like TextView, EditText, and Button in the layout files.
6. Use Intent method in Java to switch from one activity to another.
7. Register all activity classes in the manifest file.
8. Compile and execute the application.
9. Test each layout screen individually.
10. Observe the arrangement of UI components in different layouts.
